# MMd | Dieta 15 Dias

Aplicativo Android **nativo** (Java), offline, com tema futurista dark e azul neon.

## Funcionalidades
- 15 botões, um por dia, alternando cardápios A/B/C, alimentos em gramas e calorias estimadas.
- Café da manhã 07h; almoço 12h; lanche 16h; jantar 19h.
- Marcar/desmarcar refeições consumidas, com progresso diário e persistência local.
- Peso editável (111 kg inicial), meta de água = peso x 30 ml arredondada a 50 ml (3.300 ml para 111 kg).
- Registrar água por incrementos de 200/300 ml e acompanhar horários de 06:30 a 19:50.
- Notificações Android nativas com ação **Concluí**; refeições pendentes geram novo lembrete a cada ~25 min, até 22h.
- Retoma os alarmes após reinício do dispositivo. Sem login/internet.

## APK
Abra **Actions → Gerar APK Android → último run verde → Artifacts → Dieta-15-Dias-APK**. Extraia o ZIP baixado; dentro estará `app-debug.apk`, instalável no Android. Habilite instalação do navegador/gerenciador de arquivos se solicitado.

## Atenções
O Android pode atrasar alarmes aproximados por economia de bateria; habilite notificações e ajuste otimização de bateria para maior confiabilidade. Nenhum aplicativo pode obrigar a pessoa a confirmar uma refeição: o aviso continua até o usuário registrar, mas não bloqueia o aparelho.

Calorias aproximadas baseadas em porções e tabelas usuais; dependem dos rótulos e do preparo (especialmente gordura da carne moída e composto lácteo). Cardápios B/C tiveram ajustes de gramas para aproximar 2.000 kcal. Meta de água é apenas referência inicial, não tratamento para retenção; não force o consumo se houver restrições médicas.
